# Contribution plan

Use protected main where supported, short feature branches and reviewed PRs. Require scoped CI and compatible API/migration changes. Test with synthetic data on MariaDB; tenant isolation and owner-rule acceptance cases gate module completion. No automatic production deployment.

Keep PHP, TypeScript and Dart lockfiles per app; no cross-language orchestration service is mandatory. Add sanitized environment examples during actual scaffolding. Never copy Nursery credentials or real records. Record checks and not-run reasons in the canonical agent handoff.
